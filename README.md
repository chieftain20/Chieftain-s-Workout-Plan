# Chieftain's Workout Plan

An open-source, Persian-first workout planning and tracking Progressive Web App (PWA) designed for gym members.

## Overview

Chieftain's Workout Plan is a web-based fitness application focused on making structured workout planning and progress tracking simple and accessible.

The application is designed primarily for Persian-speaking users and provides a fully RTL interface, while remaining usable as a general workout planning tool.

## Features

- 🏋️ 75+ exercises with an organized exercise database
- 📋 Custom workout planning
- 📈 Progressive overload tracking
- 🎯 Weight and RIR tracking
- 📊 Workout and progress charts
- 🔗 Supersets, tri-sets and giant sets
- 📏 Body measurement tracking
- 💾 JSON data backup and restore
- ☁️ Cross-device data synchronization
- 📱 Progressive Web App (PWA) support
- ⏱️ Built-in workout timer
- 🇮🇷 Persian-first interface with full RTL support

## Live Demo

**[Open Chieftain's Workout Plan](https://chieftain20.github.io/Chieftain-s-Workout-Plan/)**

The application can be used directly in a modern web browser and installed as a PWA on supported devices.

## Open Source

This project is developed and maintained as an open-source project.

The application is currently used by the developer and other gym users, with the goal of making it useful to a broader community of Persian-speaking gym members.

## Development

The project is actively maintained and continuously improved with new features, bug fixes, usability improvements, and performance enhancements.

AI-assisted development tools are used as part of the development workflow, while the project direction, implementation decisions, testing, and maintenance are managed by the primary maintainer.
